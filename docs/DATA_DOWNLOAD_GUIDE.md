# 数据准备指南（RESSET → 本仓库）

本文回答四个问题：**下载什么、叫什么名字、放到哪里、每张表的字段是什么口径**。
所有路径与文件名都与代码实际使用的匹配规则一致，并已用真实 RESSET 导出文件核对过列名。

> 检查脚本会把本文的规则与 `config_0.ipynb` 里的常量做交叉核对；
> 两边不一致时直接报 FAIL，避免"文档说一套、代码读一套"。

## 1. 数据来源（A：下载什么）

### 1.1 数据库与访问方式

- 数据库：**RESSET 金融研究数据库**（北京聚源锐思数据科技有限公司）。
- 访问方式：由学校/机构订阅，通常通过校园网或 VPN 进入 RESSET 网页端，选择"股票"库。
- **本仓库不提供账号、不提供数据、不提供镜像**。请在获得授权的环境内自行导出。

### 1.2 导出参数（逐表）

| 项目 | 日表 | 月表 | 资产负债表 | 现金流量表 | 固定资产及折旧 |
|---|---|---|---|---|---|
| 频率 | 日频 | 月频 | 报告期（季度/年度） | 报告期 | 报告期 |
| 覆盖区间（B 线需要） | 2000-01-01 ~ 2016-12-31 | 同 | 1999 ~ 2017（含上一财年） | 同 | 同 |
| 覆盖区间（C 线需要） | **1999-01-01** ~ 2016-12-31 | 同 | 1998 ~ 2017 | 1998 ~ 2017 | 1998 ~ 2017 |
| 证券范围 | A 股（**建议只导 A 股**，见第 4.3 节） | 同 | A 股 | A 股 | A 股 |
| 报表口径 | — | — | 合并报表优先（代码不筛，见第 3.3 节） | 同 | — |
| 文件切分 | 可拆成多个年份文件 | 可拆 | 单文件 | 单文件 | 可拆 |

> 如果你手上的日表已经覆盖 1990–2026（像作者原工程那样），**不需要裁剪**：
> 读取函数会按 `start_date/final_date` 在读取时过滤，只是要多花一点 IO 时间。

### 1.3 必需 vs 补充

- **必需（缺任何一个都会让主流程报错或缺少因子）**：日表、资产负债表、现金流量表、固定资产表。
  月表为核心流程之外（C 线的月度收益与财务快照）所必需。
- **补充**：三板/上市状态表、吸收合并表。缺了只会让 `03_extended_analysis.ipynb` 中的
  壳价值相关检验显示"覆盖缺口"，不影响 CH-3 主结果。

## 2. 下载之后怎么放（B：文件夹与文件名）

### 2.1 目录结构

```text
data/
├── sample/                     # 仓库自带合成样例，不要动
└── raw/                        # ← 你的 RESSET 数据放这里
    ├── RESSET 股票_日股票综合数据/
    │   ├── RESSET_DRESSTK_2000_2010_1.csv
    │   ├── RESSET_DRESSTK_2000_2010_2.csv
    │   └── ...
    ├── RESSET 股票_月股票综合数据/
    │   └── RESSET_MRESSTK_2000-2016.csv
    ├── RESSET 股票_资产负债表/
    │   └── RESSET_BS_ALL_1.csv
    ├── RESSET 股票_现金流量表/
    │   └── RESSET_SCF_ALL_1.csv
    └── RESSET 股票_固定资产及折旧/
        └── RESSET_BSNOTE_FIXASSDEPR_1.csv
```

### 2.2 规则（重要）

| 规则 | 说明 |
|---|---|
| **目录名只影响可读性** | 代码用 `rawdata_dir.rglob(pattern)` 递归查找，任何子目录名都能找到文件 |
| **嵌套目录允许** | 可以再套一层（如 `data/raw/下载/2024-05/...`），只要文件能匹配到 |
| **文件名必须匹配 glob** | 见 0 表第 2 列。日表/月表/固定资产表用前缀通配，资产负债表与现金流量表**必须**叫 `RESSET_BS_ALL_1.csv` / `RESSET_SCF_ALL_1.csv` |
| **支持多分片** | 日表按月/按年/按行数拆成 40 个文件都可以，读取时 `sorted()` 排序后 `concat()` 拼接 |
| **可以改文件名** | 只要保持前缀与 `.csv` 后缀，例如 `RESSET_DRESSTK_2011_2015_part1.csv` |
| **不要放 zip** | 读取函数不会解压；`*.zip` 会被检查脚本提示 WARN |
| **不要留重复目录** | 形如 `(2021-2025) (1)` 的副本会被一并读入，行数翻倍（见 5） |

### 2.3 找不到文件时会怎样

读取函数的行为是"匹配不到就返回空列表"，随后 `pd.concat([])` 会抛出
`ValueError: No objects to concatenate`。为避免这种难以定位的报错，
**先跑检查脚本**：

```bash
python scripts/check_data_layout.py            # 检查 data/raw
python scripts/check_data_layout.py --deep     # 追加主键/分片重复检查
```

## 3. 每张表的字段口径（C：字段、单位、时间）

逐字段的完整清单见 [DATA_SCHEMA.md](DATA_SCHEMA.md)。这里只强调**最容易搞错的几点**，
每一点都用真实导出文件核对过。

### 3.1 收益率与价格单位

| 字段 | 真实取值示例 | 单位 | 说明 |
|---|---|---|---|
| `Dret`（日收益） | `0.0146` | **小数**（0.0146 = 1.46%） | 代码直接做 `(1+x).prod()-1`；若导成百分数，月收益会被放大 100 倍 |
| `DRfRet`（日无风险） | `0.000125` | **小数** | 与 `Dret` 同口径 |
| `Clpr`（收盘价） | `16.0200` | 元 | **未复权**收盘价；代码不读 `AdjClpr1/2` |
| `Fullshr`（总股本） | `3485013762` | 股 | 市值 = `Clpr × Fullshr`（元） |
| `Trdvol` / `Trdsum` | `35884061` / `573343723.86` | 股 / 元 | 用于换手率与非流动性（Amihud） |
| `PB` / `PE` | `1.81` / `8.88` | 倍 | `BM = 1/PB` |
| `EPS` | `0.49` | 元/股 | 报告期**累计**口径（Q3 即前三季度），代码未年化 |
| `ROE` | `5.2912` | **百分数**（5.29%） | 代码直接把它当排序信号用，未除以 100 |
| `Monret` / `Monrfret` | `0.0284` | 小数 | 月表收益字段 |

> **待核实**：`Dret` 的复权与分红处理（RESSET 数据词典中的正式定义）本仓库未逐字核对。
> 代码只使用 `Dret` 字段本身，不从价格重算收益；若你的导出把 `Dret` 设为"不含分红"，
> 与论文口径会存在系统性差异。

### 3.2 时间口径

| 字段 | 含义 | 代码怎么用 |
|---|---|---|
| `Date` | 交易日 / 月末日 | 形成月 `form = Date` 的年月；持有月 `ym = form + 1` |
| `Enddt`（日表/月表） | 财务字段对应的**报告期末** | 只用于与资产负债表按 `(股票, 报告期)` 对齐；**不能**当作可用日 |
| `Infopubdt` | 财务字段的**公告日** | point-in-time 对齐的可用日：`merge_asof(direction='backward')` |
| `Reporttype` | `Q1/Q2/Q3/Q4` | 年度事件只保留 `Q4`（年报） |

### 3.3 财务表：代码**没有**做的筛选（必须在文档里说清楚）

- 资产负债表与现金流量表带有 `ConFlg`（合并/母公司）、`AccStd`（会计准则）、
  `AdjFlg`（是否调整）等口径字段，**代码不读这些列**，因此同一 `(股票, 报告期)`
  可能同时存在合并与母公司两个版本。去重规则是"按 `(股票, 报告期)` 取排序后的最后一条"，
  不保证一定取到合并报表。
- 固定资产及折旧表只保留 `FixAssType = '99999'`（合计行）与 `ReportType = 'Q4'`。
- 财务表的 `A_StkCd` 会有空值（B/H 股行），清洗阶段 `dropna` 会丢弃。

### 3.4 一张表的字段清单模板

每张表在 [DATA_SCHEMA.md](DATA_SCHEMA.md) 中都按以下 12 项列出：

| 项目 | 内容 |
|---|---|
| RESSET 表名 | 官方数据表名称 |
| 文件名模式 | CSV 匹配规则 |
| 数据频率 | 日频 / 月频 / 报告期 |
| 一行代表 | 股票×交易日、股票×月份、股票×报告期 |
| 唯一键 | 例如 `(Stkcd, Date)` |
| 必需字段 | 代码实际读取的列 |
| 字段含义 | 每个关键变量的经济含义 |
| 字段单位 | 元 / 股 / 倍 / 小数 / 百分数 |
| 时间口径 | 交易日 / 报告期 / 公告日 / 形成月 |
| 缺失值处理 | 代码实际采用的方式 |
| 用途 | 对应因子、组合或论文实验 |
| 读取函数 | 实际使用该表的函数 |

## 4. 数据时间范围（D）

### 4.1 两条线用的是不同的起始日（这不是笔误）

| 代号 | 常量 | 值 | 为什么 |
|---|---|---|---|
| B 线 | `config_0.ipynb: start_date / final_date` | `2000-01-01 ~ 2016-12-31` | 通用因子工作流的样本期，与论文研究期一致 |
| C 线 | `reproduction_pipeline/00_ch3_config.ipynb` 覆盖为 | `1999-01-01 ~ 2016-12-31` | **预热窗口**：12-1 动量需要 11 个月历史、12 月换手率需要 250 个交易日、Dimson beta 需要 250 个交易日 + 5 阶滞后 |

因此**原始数据不能只从 2000-01 开始下载**：C 线需要 1999 年（甚至 1998 年）的日行情，
否则 2000 年前十个月的动量、换手、beta 全是缺失，样本前期会整段丢掉。

### 4.2 财务数据需要的历史长度

- 资产增长、应计、NOA 都要做**相邻两年**的差分 → 至少需要 1999 年年报。
- CSMAR/RESSET 的财报覆盖往往从 1998–1999 年开始，早期覆盖不全属于已知限制，不要用
  "补造数据"的方式填平。

### 4.3 有效月份数

严格实施"形成月至少有 15 个交易日"之后，本地样本得到 **199 个月**（论文称 204 个月）。
缺口月份（2000-03、2001-02、2002-03、2004-02、2005-03）**没有被放宽条件补齐**，
这是与原文的一处真实差异，见 [REPRODUCTION_STATUS.md](REPRODUCTION_STATUS.md)。

## 5. 常见错误与修复（F）

| 症状 | 原因 | 修复 |
|---|---|---|
| `Usecols do not match columns ... 'TotCurLia'` | 资产负债表列名不对（注意 `TotCurrAss` 是双 r、`TotCurLia` 是单 r） | 重新导出资产负债表，或用检查脚本确认列名 |
| `KeyError: 'ClPr'` / `'Clpr'` | 日表是 `Clpr`、月表是 `ClPr`，大小写不同 | 检查脚本会分别校验；不要手工改列名 |
| `ValueError: No objects to concatenate` | 某张表一个文件都没匹配到 | 跑 `check_data_layout.py`，按提示改文件名 |
| 月收益数量级异常大（>10） | `Dret/Monret` 被导成百分数 | 重新导出为小数；检查脚本会报 FAIL |
| 内存不足 / 运行极慢 | 日表被重复下载（`(1)` 副本目录） | 删除重复目录；`--deep` 会提示"共享股票代码且区间重叠" |
| 财务字段大量缺失 | 只导了近几年的财报 | 补下载 1998 年起的三张表 |
| `Listedstate` 里没有 `Norm` | 导错列或导错表 | 检查脚本会报 FAIL；`universe()` 只保留 `Norm` |

## 6. 数据与论文实验的对应关系（E）

| 数据表 | 进入哪个环节 | 影响哪些论文实验 |
|---|---|---|
| 日表 `Clpr × Fullshr` | `get_market_feature` → 市值 | 一切规模排序、市值加权、SMB、MKT |
| 日表 `Dret / DRfRet` | `get_excess_return` → 日超额收益；`get_ym_monthly_excessret` → 月收益 | 所有因子收益、alpha、GRS、贝叶斯比较 |
| 日表 `Dret`（滚动） | 波动率、MAX、反转 | Table 6 的 Vol / MAX / 1M Ret 三个异象 |
| 日表 `Trdvol / Fullshr` | 换手率、异常换手率 | Table 6 Turnover 异象、CH-4 的换手因子 |
| 日表 `Trdsum / Dret` | Amihud 非流动性 | Table 6 流动性异象 |
| 日表 `PB` | `1/PB = BM` | Table 2 的 BM 赛马、FF-3 的 HML |
| 日表 `EPS / Clpr` | EP | **CH-3 的 VMG**、Table 2 的 EP 赛马 |
| 日表 `ROE` | 盈利能力代理 | FF-5 的 RMW 代理、Table 6 ROE 异象 |
| 月表 `Monret / Monrfret` | C 线月度收益 | C 线全部因子与检验的收益来源 |
| 月表 `EPS/PB/ROE + Infopubdt` | C 线 04 步的月末信号（月表优先、日表回退） | CH-3 排序、EP 赛马 |
| 资产负债表 `TotAss` | 资产增长、AM | FF-5 投资因子代理、Table 2 的 AM 赛马 |
| 资产负债表（流动/负债/借款/货币资金） | 应计利润、NOA | 应计/NOA 异象、稳健性 |
| 现金流量表 `CENetIncr` | CP = 净现金流 / 市值 | Table 2 的 CP 赛马、CP 异象 |
| 现金流量表摊销 + 固定资产折旧 | 应计利润的 Dep 项 | 应计异象 |
| 三板/上市状态表 | 上市状态与资格辅助 | 扩展分析（可选） |
| 吸收合并表 | 借壳事件代理 | 壳价值扩展分析（可选，且**不是**论文的 133 起借壳事件） |
