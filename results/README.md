# results/ —— 已计算结果摘要

## 这里放的是什么

**不是**新鲜的运行产物，而是把 **2026-10 那次完整真实数据运行**中得到的关键结果**摘录**下来，
方便审阅时不必打开 Notebook 也能看到量级与方向。

## 来源与限制（重要）

| 项目 | 说明 |
|---|---|
| 数据来源 | 作者本机 RESSET 全样本（约 12 GB，**未随仓库分发**） |
| 运行时间 | 2026-10（见 ~~06_reproduction_report.ipynb~~ 顶部日期） |
| 本轮是否重跑 | **没有**。本仓库整理时未在真实数据上重新执行完整流水线 |
| 能否用样例数据复现 | **不能**。~~data/sample~~ 是随机生成的合成数据，跑出来的数字没有经济学含义 |
| 如何自己生成 | 按 [docs/DATA_DOWNLOAD_GUIDE.md](../docs/DATA_DOWNLOAD_GUIDE.md) 准备数据，运行 ~~CH_3_factors.ipynb~~ |

因此本目录的定位是"**历史结果存档 + 溯源索引**"，不是"本仓库已验证的结果"。
每份摘要都标注了生成它的代码入口，便于逐个复核。

## 为什么没有把 Notebook 输出直接导出成 CSV

1. Notebook 输出里混杂真实个股行（受限数据），不能进仓库；
2. 旧输出容易被误认为"本次运行结果"；
3. 真正的可核验方式是按代码入口重跑，而不是归档一份无法追溯的表格。
