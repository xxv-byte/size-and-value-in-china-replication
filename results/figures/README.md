# figures/ —— 图表说明

本仓库**不附带**历史运行生成的图片文件，原因有三：

1. 原工程把图输出到本地临时目录，没有纳入版本管理，无法确认每张图的生成参数；
2. 论文原图（Fig. 1–2、Fig. A1）属于出版社版权内容，仓库不转录、不复制；
3. 把旧图片放进仓库，容易被误认为"本次运行结果"。

## 需要的图怎么生成

| 图 | 生成入口 | 说明 |
|---|---|---|
| CH-3 三因子累计收益 | ~~07_factor_returns.ipynb~~ 的 ~~f_ch3~~ 自行绘图 | 需真实数据 |
| 异象 alpha 对比（CAPM vs CH-3） | ~~CH3_核心解释实验.ipynb~~ 输出的对照表 | 需真实数据 |
| 贝叶斯比较曲线（Fig. A1） | ~~07_bayesian_comparison.ipynb~~ | 需真实数据 |
| 月度覆盖率 / 样本月份 | ~~06_reproduction_report.ipynb~~ | 需真实数据 |

## 关于论文原图

~~00_paper_targets.ipynb~~ 里有一个 ~~show_original_figure_page()~~ 辅助函数，
会用 PyMuPDF 打开**你自己准备的论文 PDF**并显示对应页。该函数默认被注释掉，
仓库不包含论文 PDF。
